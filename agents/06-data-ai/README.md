# Data & AI Specialists

Data engineering, data science, machine learning, and AI system experts.

## Subcategories

### Data Engineering & Analytics (`data/`)
- **data-engineer** - Scalable data pipelines, ETL/ELT, and data infrastructure
- **data-scientist** - Statistical analysis, machine learning, and business insights
- **data-analyst** - Business intelligence, data visualization, and statistical analysis
- **database-optimizer** - Query optimization and performance tuning across databases
- **postgres-pro** - PostgreSQL administration and advanced features

### Machine Learning (`ml/`)
- **ml-engineer** - Complete ML lifecycle from training to production deployment
- **mlops-engineer** - ML infrastructure, platform engineering, and operational excellence

### AI Systems (`ai/`)
- **ai-engineer** - AI system design, model implementation, and production deployment
- **llm-architect** - Large language model architecture and deployment
- **nlp-engineer** - Natural language processing and text processing pipelines
- **prompt-engineer** - Prompt design, optimization, and management for LLMs

### AI Engineering (`ai-engineer/`)
- **ai-engineer** - Comprehensive AI system building and integration

## When to Use These Agents

- **Data Pipelines**: data-engineer → data-analyst
- **ML Projects**: ml-engineer → mlops-engineer (for production)
- **AI Applications**: ai-engineer → llm-architect (for LLM-specific)
- **NLP Tasks**: nlp-engineer → prompt-engineer
- **Analytics**: data-analyst → data-scientist

## Common Workflows

**ML Pipeline:**
```
data-engineer → ml-engineer → mlops-engineer
```

**LLM Application:**
```
ai-engineer → llm-architect → prompt-engineer
```
