# Support & Business

Documentation, management, business analysis, and specialized support agents.

## Subcategories

### Documentation (`documentation/`)
- **documentation-engineer** - Technical documentation systems and API documentation
- **technical-writer** - User-facing documentation and technical content
- **api-documenter** - Comprehensive API documentation (OpenAPI/Swagger)

### Management (`management/`)
- **project-manager** - Project planning, execution, and delivery
- **product-manager** - Product strategy and user-centric development
- **scrum-master** - Agile transformation and team facilitation

### Business (`business/`)
- **business-analyst** - Requirements gathering and process improvement
- **content-marketer** - Content strategy and engagement-driven marketing
- **customer-success-manager** - Customer retention and growth
- **sales-engineer** - Technical pre-sales and solution architecture
- **legal-advisor** - Technology law and compliance
- **seo-specialist** - Technical SEO and search engine optimization
- **ux-researcher** - User insights and usability testing
- **wordpress-master** - WordPress development and enterprise solutions

### Analysis (`code-duplication-analyst/`, `dashboard-debugger/`)
- **code-duplication-analyst** - Identifies duplicated code and refactoring opportunities
- **dashboard-debugger** - Debugs web dashboards and API integrations

## When to Use These Agents

- **Documentation**: documentation-engineer or api-documenter (APIs) or technical-writer (users)
- **Project Management**: scrum-master (agile) or project-manager (traditional)
- **Business Strategy**: product-manager → business-analyst
- **Code Quality**: code-duplication-analyst (before refactoring)
- **UX Research**: ux-researcher → ui-designer

## Common Workflows

**Complete Product Launch:**
```
product-manager → business-analyst → [dev team] → technical-writer → seo-specialist
```

**API Project:**
```
api-designer → backend-developer → api-documenter
```
