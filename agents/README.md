# Claude Agents Library

A comprehensive collection of specialized AI agents organized by function and domain expertise.

## 📁 Folder Structure

### 00-orchestration/
**Meta-agents that coordinate other agents**
- Start here for complex projects
- Manages multi-agent workflows
- Handles task distribution and dependencies

### 01-development/
**Core development agents organized by stack**
- `backend/` - API, microservices, server-side development
- `frontend/` - UI/UX, web interfaces, design systems
- `mobile/` - iOS, Android, cross-platform mobile apps
- `fullstack/` - End-to-end application development

### 02-languages/
**Programming language specialists**
- `web/` - JavaScript, TypeScript, PHP, SQL
- `systems/` - C++, Rust, Go, Java, C#
- `scripting/` - Python, Ruby, Perl

### 03-frameworks/
**Framework-specific experts**
- `frontend/` - React, Vue, Angular, Next.js
- `backend/` - Django, Rails, Laravel, Spring Boot, .NET
- `mobile/` - Flutter, React Native, Swift, Kotlin

### 04-infrastructure/
**DevOps, cloud, and security**
- `cloud/` - AWS, Azure, GCP architects
- `devops/` - CI/CD, Kubernetes, monitoring, deployment
- `security/` - Security engineering, auditing, compliance

### 05-quality/
**Testing, review, and optimization**
- `testing/` - QA, test automation, accessibility
- `review/` - Code review, architecture review
- `performance/` - Optimization, debugging, performance engineering

### 06-data-ai/
**Data science and AI specialists**
- `data/` - Data engineering, analysis, databases
- `ml/` - Machine learning, MLOps
- `ai/` - AI systems, LLMs, NLP

### 07-specialized/
**Domain-specific experts**
- `fintech/` - Financial technology, payments
- `blockchain/` - Crypto, smart contracts
- `gaming/` - Game development
- `iot/` - Internet of Things, embedded systems

### 08-support/
**Documentation and business support**
- `documentation/` - Technical writing, API docs
- `management/` - Project/product management
- `business/` - Business analysis, marketing, legal

### 09-utilities/
**Helper agents and tools**
- Research and analysis tools
- Development workflow helpers
- Universal utilities

## 🚀 Quick Start

1. **For new projects**: Start with `00-orchestration/tech-lead-orchestrator`
2. **For specific tasks**: Navigate to the appropriate category
3. **For guidance**: See `AGENT_SELECTION_GUIDE.md`

## 📋 Key Files

- `AGENT_SELECTION_GUIDE.md` - Detailed guide for choosing agents
- `reorganize_agents.ps1` - Script used to organize agents into folders

## 🔗 Agent Chaining

Agents can be chained for complex workflows:
```
tech-lead-orchestrator → backend-developer → frontend-developer → qa-expert
```

See the Agent Selection Guide for common chains and patterns.
