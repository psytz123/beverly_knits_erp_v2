# Development Agents

Core development agents for building applications across all layers.

## Subcategories

### Backend Development (`backend/`)
- **backend-developer** - Senior backend engineer for scalable APIs and microservices
- **api-designer** - API architecture and design specialist
- **graphql-architect** - GraphQL schema design and implementation
- **microservices-architect** - Distributed systems and microservices expert
- **websocket-engineer** - Real-time communication specialist

### Frontend Development (`frontend/`)
- **frontend-developer** - Expert UI engineer for robust frontend solutions
- **ui-designer** - Visual design and user interface specialist

### Fullstack Development (`fullstack/`)
- **fullstack-developer** - End-to-end feature development across all layers
- **electron-pro** - Cross-platform desktop application specialist

### Mobile Development (`mobile/`)
- **mobile-developer** - Cross-platform mobile specialist
- **mobile-app-developer** - Native and cross-platform mobile expert

## When to Use These Agents

- **New Feature Development**: Start with fullstack-developer or specific layer specialist
- **API Projects**: Use api-designer → backend-developer
- **Frontend Projects**: Use frontend-developer or ui-designer
- **Mobile Apps**: Use mobile-developer or mobile-app-developer
- **Desktop Apps**: Use electron-pro

## Common Workflows

**Full-Stack Feature:**
```
api-designer → backend-developer → frontend-developer
```

**Microservices Project:**
```
microservices-architect → backend-developer → deployment-engineer
```

**Mobile App:**
```
mobile-app-developer → backend-developer (for API) → qa-expert
```
