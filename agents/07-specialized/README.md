# Specialized Domain Experts

Industry-specific and niche technology specialists for specialized applications.

## Subcategories

### Financial Technology (`fintech/`)
- **fintech-engineer** - Financial systems and regulatory compliance
- **quant-analyst** - Quantitative analysis and algorithmic trading
- **risk-manager** - Risk assessment and compliance frameworks
- **payment-integration** - Payment gateway integration and PCI compliance

### Blockchain (`blockchain/`)
- **blockchain-developer** - Smart contracts, DApps, and DeFi protocols

### Gaming (`gaming/`)
- **game-developer** - Game engine programming and multiplayer systems

### Integration (`integration/`)
- **integration-researcher** - Discovering and documenting external software integration methods
- **web-api-cookie-specialist** - Web API authentication via cookies and session management

### IoT & Embedded (`iot/`)
- **iot-engineer** - Connected devices, edge computing, and IoT platforms
- **embedded-systems** - Microcontroller programming and RTOS development

### Supply Chain (`supply-chain/`)
- **supply-chain-orchestrator** - End-to-end supply chain optimization and logistics

## When to Use These Agents

- Use when working in specialized domains requiring industry expertise
- These agents understand domain-specific regulations, standards, and best practices
- Combine with general development agents for complete solutions

## Example Workflows

**FinTech App:**
```
fintech-engineer → payment-integration → security-auditor
```

**IoT Solution:**
```
iot-engineer → embedded-systems → cloud-architect
```
