# Framework Specialists

Framework-specific experts with deep knowledge of specific web, mobile, and backend frameworks.

## Subcategories

### Backend Frameworks (`backend/`)
- **spring-boot-engineer** - Spring Boot 3+ with cloud-native patterns and microservices
- **rails-expert** - Rails 7+ with modern conventions and Hotwire/Turbo
- **laravel-specialist** - Laravel 10+ with elegant PHP and enterprise features
- **django-developer** - Django 4+ with scalable web applications and REST APIs
- **dotnet-core-expert** - .NET 8 with modern C# and cross-platform development
- **dotnet-framework-4.8-expert** - Legacy .NET Framework for Windows enterprise apps

### Frontend Frameworks (`frontend/`)
- **react-specialist** - React 18+ with modern patterns and ecosystem
- **vue-expert** - Vue 3 with Composition API and Nuxt 3
- **nextjs-developer** - Next.js 14+ with App Router and server components
- **angular-architect** - Angular 15+ with enterprise patterns and RxJS

### Mobile Frameworks (`mobile/`)
- **flutter-expert** - Flutter 3+ for cross-platform mobile with native performance
- **swift-expert** - Swift 5.9+ for iOS/macOS development
- **kotlin-specialist** - Kotlin for Android and multiplatform development

## When to Use These Agents

- Use framework specialists when working within a specific framework
- They understand framework conventions, best practices, and ecosystem tools
- Prefer these over generic language specialists for framework-specific work
