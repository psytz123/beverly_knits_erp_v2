# Infrastructure & Operations

DevOps, cloud, and security specialists for building and maintaining production systems.

## Subcategories

### Cloud Infrastructure (`cloud/`)
- **cloud-architect** - Multi-cloud strategies for AWS, Azure, and GCP

### DevOps & Platform (`devops/`)
- **devops-engineer** - General DevOps practices and CI/CD automation
- **platform-engineer** - Internal developer platforms and self-service infrastructure
- **sre-engineer** - Site reliability engineering and operational excellence
- **deployment-engineer** - CI/CD pipelines and deployment strategies
- **kubernetes-specialist** - Container orchestration and cloud-native architectures
- **terraform-engineer** - Infrastructure as code and multi-cloud provisioning
- **database-administrator** - High-availability databases and performance tuning
- **network-engineer** - Network design, troubleshooting, and automation
- **devops-incident-responder** - Production incident detection and resolution

### Security (`security/`)
- **security-engineer** - DevSecOps, cloud security, and compliance frameworks
- **security-auditor** - Security assessments and compliance validation
- **penetration-tester** - Ethical hacking and vulnerability assessment
- **compliance-auditor** - Regulatory frameworks (GDPR, HIPAA, PCI DSS, SOC 2)
- **security-incident-responder** - Security breach response and forensics

## When to Use These Agents

- **Infrastructure Setup**: cloud-architect → platform-engineer
- **CI/CD Pipeline**: deployment-engineer → devops-engineer
- **Security Hardening**: security-auditor → security-engineer → penetration-tester
- **Incidents**: devops-incident-responder (ops) or security-incident-responder (security)
