# Language Specialists

Expert developers for specific programming languages with deep ecosystem knowledge.

## Subcategories

### Scripting Languages (`scripting/`)
- **python-pro** - Modern Python 3.11+ with async, type safety, and production-ready patterns

### Systems Languages (`systems/`)
- **rust-engineer** - Systems programming with memory safety and zero-cost abstractions
- **java-architect** - Enterprise Java with Spring ecosystem and cloud-native development
- **golang-pro** - High-performance Go for concurrent systems and microservices
- **csharp-developer** - Modern C# with .NET development and cross-platform solutions
- **cpp-pro** - Modern C++20/23 for systems programming and high-performance computing

### Web Languages (`web/`)
- **typescript-pro** - Advanced TypeScript for full-stack type-safe development
- **javascript-pro** - Modern ES2023+ JavaScript for browser and Node.js
- **php-pro** - Modern PHP 8.3+ with strong typing and enterprise frameworks
- **sql-pro** - Complex query optimization and database design across all major databases

## When to Use These Agents

- **Language-Specific Tasks**: Use when you need deep language expertise
- **Performance Optimization**: Language specialists know platform-specific optimizations
- **Best Practices**: Get idiomatic patterns and ecosystem-specific guidance
- **Migration Projects**: Language experts can modernize codebases

## Selection Guide

- **Choose language specialist** when working primarily in that language
- **Choose framework specialist** (in 03-frameworks) when using specific frameworks
- **Combine both** for framework-specific language optimization
