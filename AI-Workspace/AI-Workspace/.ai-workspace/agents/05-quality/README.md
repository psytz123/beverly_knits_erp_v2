# Quality Assurance & Testing

Code review, testing, performance, and debugging specialists ensuring software quality.

## Subcategories

### Code Review (`review/`)
- **code-reviewer** - Code quality, security vulnerabilities, and best practices across languages
- **architect-reviewer** - System design validation and architectural patterns

### Testing (`testing/`)
- **qa-expert** - Comprehensive QA, test strategy, and quality metrics
- **test-automator** - Test automation frameworks and CI/CD integration
- **chaos-engineer** - Controlled failure injection and resilience testing
- **accessibility-tester** - WCAG compliance and inclusive design validation

### Performance & Debugging (`performance/`)
- **performance-engineer** - System optimization and bottleneck identification
- **error-detective** - Complex error pattern analysis and root cause discovery
- **debugger** - Complex issue diagnosis and systematic problem-solving

## When to Use These Agents

- **Code Quality**: code-reviewer (after implementation)
- **Architecture**: architect-reviewer (during design phase)
- **Testing Strategy**: qa-expert → test-automator
- **Performance Issues**: performance-engineer → error-detective → debugger
- **Accessibility**: accessibility-tester (before production)
- **Resilience**: chaos-engineer (for production systems)

## Common Workflows

**Quality Gate:**
```
code-reviewer → test-automator → qa-expert
```

**Performance Optimization:**
```
performance-engineer → debugger → code-reviewer
```
