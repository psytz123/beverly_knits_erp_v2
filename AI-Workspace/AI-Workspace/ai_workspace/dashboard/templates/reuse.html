Understanding Reuse Analysis

High Reuse (≥70%): Excellent! Existing code can be reused with minimal changes. Auto-approved for creation.

Medium Reuse (30-69%): Good match found. Review existing implementation before creating new code.

Low Reuse (<30%): New implementation needed. Ensure it follows coding standards and is well-documented.
