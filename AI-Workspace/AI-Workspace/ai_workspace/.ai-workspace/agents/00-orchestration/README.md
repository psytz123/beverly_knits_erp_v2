# Orchestration Agents

These meta-agents coordinate and manage other agents for complex workflows.

## Available Agents

- **tech-lead-orchestrator** - Analyzes projects and assigns tasks to appropriate sub-agents
- **agent-health-monitor** - Ensures continuous agent operation with automatic recovery
- **multi-agent-coordinator** - Manages complex multi-agent workflows and communication
- **agent-organizer** - Assembles optimal agent teams for specific tasks
- **workflow-orchestrator** - Orchestrates sequential and parallel agent workflows
- **task-distributor** - Distributes work efficiently across multiple agents
- **context-manager** - Manages shared context between agents
- **error-coordinator** - Coordinates error handling across agent teams
- **knowledge-synthesizer** - Synthesizes insights from multiple agents
- **performance-monitor** - Monitors agent performance and system health
- **project-analyst** - Analyzes project requirements and structure
- **team-configurator** - Configures optimal agent teams
- **workspace-initializer** - Sets up agent collaboration workspace
- **context-compressor** - Compresses context to prevent agent overload

## When to Use

Always start with these agents for:
- Complex multi-step projects
- Tasks requiring multiple specialists
- Coordinating parallel work streams
- Managing dependencies between tasks
